# 📚 StudyFree

> Learn anything. Totally free. No account. No paywall. Ever.

**StudyFree** is a Quizlet-like flashcard study app that runs entirely in a single HTML file — no server, no login, no cost. Just open it and start learning.

🌐 **Live Site:** [yallcode.github.io/studyfree](https://yallcode.github.io/studyfree)

---

## ✨ Features

- **Flashcards** — Flip cards, track progress, shuffle, star cards, full keyboard shortcuts
- **Learn Mode** — Mix of multiple choice and written questions, adapts each round
- **Write Mode** — Type answers yourself, see what you missed
- **Spell Mode** — Hear the term spoken aloud (TTS), type its definition
- **Test Mode** — Full test with multiple choice, true/false, and written questions mixed
- **Match Game** — Race the clock to match pairs; adjustable size (6/8/10 cards)
- **Gravity Game** — Terms fall from the sky, type definitions before they hit the ground
- **All Terms** — Browse every card; filter by starred
- **Starred Cards** — Star any card, study only starred in any mode
- **Settings** — Swap sides, shuffle, Know It buttons, flip answer direction
- **Import** — Paste tab/pipe/comma-separated pairs to build sets instantly
- **Export** — Copy your entire set to clipboard in one click
- **100% Offline** — Everything in localStorage, no internet needed after first load
- **Mobile Friendly** — Fully responsive on phones and tablets

## 🚀 Getting Started

No installation needed. Just open the file!

### Option 1 — Use the live site
Visit [yallcode.github.io/studyfree](https://yallcode.github.io/studyfree) in any browser.

### Option 2 — Run it locally
```bash
git clone https://github.com/yallcode/studyfree.git
cd studyfree
# Just open index.html in your browser — done!
```

### Option 3 — Host your own copy
1. Fork this repo
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://YOUR-USERNAME.github.io/studyfree`

## 🗂️ How to Use

### Creating a Set
1. Click **+ Create Set** in the top right
2. Give your set a title and optional description
3. Add terms and definitions (minimum 2 cards)
4. Hit **Save Set**

### Studying
Open any set from your dashboard, then pick a mode:

| Mode | Description |
|------|-------------|
| Flashcards | Click a card to flip between term and definition |
| Quiz | Answer multiple choice questions, get a score at the end |
| Match | Tap pairs of matching terms and definitions as fast as you can |
| All Terms | View all cards in the set in a scrollable list |
